## 1. Overarching Job Goal & Acceptance Criteria
> **PRIMARY GOAL:** Port the BEJSON/MFDB **Core family** (the modules that exist in Lib_PY, Lib_JS, Lib_TS and Lib_SH) to pure Java with 100% behavioural parity against the frozen libraries_104 Python reference, buildable as a plain Gradle java-library and consumable from Android apps. Frozen libraries are not modified.

### Key Acceptance Criteria
- [x] Java 8 language level, zero third-party dependencies, no android.* imports, no javax.* / java.awt / java.lang.management.
- [x] No System.out/err printing in library code (java.util.logging only); no hardcoded absolute paths in logic.
- [x] Modules ported: errors, core (+field map, PID lock, atomic write), env, path_guard, validator, schema, parse, core_nesting, chunking (+MFDB-132), mfdb_core (+MFDBArchive), mfdb_validator.
- [x] Python-compatible JSON layer (parse, dumps indent=2, ensure_ascii, float repr, Python == semantics).
- [x] Python test suites' behaviours covered by oracle drivers (the four unittest files themselves not literally ported).
- [x] Cross-language parity fixtures: Python generates, Java reproduces identical bytes/results.
- [x] Out of scope (per user): md_to_html and Python-only extras (provider, static_backend, state_management, list_validator, 104db_parser, cli/).
